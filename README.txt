Publish free with GitHub Pages:
1. Create a new GitHub repository.
2. Upload all files and the assets folder (keep the same folder structure).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the website. Your site address will appear in Settings > Pages.

Before publishing, review your contact details and project descriptions.
